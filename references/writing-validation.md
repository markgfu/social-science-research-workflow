# 写作与验证模式

写作、综述、研究含义解释及文字修改前，必须读取 [作者判断与证据规范](author-judgment-writing.md)。先检索 AMJ、《求是》等真实原文，核对1—3个与当前任务匹配的参照及段落锚点，再处理当前文本的问题。没有核读原文，不声称已完成对照。

在内部明确段落的问题、判断和依据。每段只承担一个主要任务，段落之间由问题、证据或推论推进；不强制首句、句序和结尾使用固定模板。背景与综述仅保留当前论证需要的信息。结果讨论解释发现怎样改变已有认识，不换词重复结果或泛称其意义。

## `writing`：维护论证闭环

### 研究问题

把宽泛领域收敛为具体对象、关系、时空边界和可回答形式，同时检查文献与证据可得性。输出候选问题、可行性判断和缺口；不要因为题目新颖便跳过证据条件。

### 文献动机

从核验后的文献生态推出研究问题：已有认识是什么、哪里不足或冲突、当前研究做什么、为何重要。理论/实证、跨国/单国、定性/定量、当代/历史、因果/机制等对照只能作为检索诊断，不能自动生成缺口。

### 背景

背景负责定位问题并连接动机与设计。为每条背景信息记录后文承接点；若它触发内生性、制度选择或执行偏差，必须进入设计威胁或限制，不能为了叙事便利隐藏。

### 数据

分开写样本和变量：

- 样本：范围、时间、单位、观测数、来源、形成过程、代表性和限制。
- 变量：结果变量、核心解释变量、控制变量、定义、测量、理由、时空分布和缺失处理。

背景侧重制度和叙事信息，数据部分侧重可审计的统计信息。图表需有文字解释。

### 研究设计

研究设计不是方法名。至少写清：

```text
识别/回答目标
→ 最大威胁
→ 为什么选择该设计
→ 如何实施
→ 核心假设与所需证据
→ 假设失败的后果
→ 验证与解释边界
```

不要仅凭题目自动推荐 DID、IV、RDD 或其他方法。具体方法是否适用必须查相应方法证据。

### 闭环检查

逐项确认研究问题、文献动机、背景、数据、设计和结果主张使用相同对象、范围和估计目标。每个强主张必须有强度相称的证据；断链则回退修改，不用后续段落补造前提。

## `validation`：从威胁路由证据

### 内生性与识别威胁

从反事实和选择过程出发，检查测量偏误、与核心解释变量相关的遗漏因素、互为因果和动态/自回归结构。还要检查样本选择、溢出、处理定义、时间错配、外部效度和研究领域特有威胁。

输出“威胁—假设—现有证据—缺失证据—主张影响”登记表。不要把所有遗漏都叫内生性，也不要宣称某方法自动解决某威胁。

### 稳健性矩阵

按实际威胁选择检验：

| 威胁 | 候选证据 |
|---|---|
| 样本/测量生成 | 替代来源、替代构造、范围敏感性 |
| 推断效率 | 与相关结构匹配的标准误或随机化推断 |
| 模型形式 | 与数据分布和目标量一致的替代估计 |
| 混杂/设定 | 有理论依据的控制、固定效应、趋势或设计诊断 |
| 识别假设 | 具有不同假设的替代设计或敏感性分析 |
| 替代解释 | 预先写清可观察预测的安慰剂/负向控制 |

每项记录：目标威胁、改动、预期、结果、对主张的影响。保留失败、反向和不显著结果；不要以检验数量或显著星号评价稳健性。

### 异质性

回答效应对谁、何时、何地不同。分组须有事前理论、制度或文献理由；报告组间差异与不确定性。不能因一组显著另一组不显著就断言组间不同，也不能自动把异质性写成机制。

### 机制

先由理论或文献推出 `X → 中介过程 → Y` 的可区分预测，再匹配证据。

- 单一机制：既需支持路径，也需处理关键竞争机制。
- 多机制：分别列出预测、证据与支持强度，允许部分不支持。
- 代理变量、分组或加入中介后的系数变化通常不足以单独证明机制。
- 数据不支持直接检验时，明确写间接证据或 `needs-verification`。

异质性和机制不是每项研究的必需模块。允许输出“不应做”及理由。

## 写作输出

在工作材料中维护简短 claim-evidence ledger：主张、类别、来源锚点、证据等级和状态。未支持主张应削弱、删除或保留验证标记。证据缺口实质影响判断时，在交付中准确说明。

交付前自行检查判断、内容依据、语言和作者理解，发现问题直接修改。默认交付成稿；用户要求证据审查、审稿或修改说明时再附相应表格和分析。不默认附上内部质检过程、段落角色标签或逐项自检清单。
